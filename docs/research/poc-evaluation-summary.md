# 선행 PoC 평가 요약

이 수치는 `pakyeon/wadiz-story-ai-poc`의 2026-08-17 종료 상태를 요약한다. 이 저장소는
원본 WAi 결과나 실험 원장을 복사하지 않고 구현 결정에 필요한 결론만 보존한다.

## 범위

- 제품군: 로봇청소기
- 정식 비교: E01~E08
- 비교 단위: 동일한 최종 입력 정보의 기준 시스템 결과와 로컬 PoC 결과
- 1차 평가자: Codex
- 최종 평가자: 사용자

## 결과

| 지표 | 결과 |
|---|---:|
| 관찰 핵심 질문·확인·생성 상태 | 8/8 |
| E03~E08 관찰 경로 회귀 재생 | 6/6 |
| 신규 로봇청소기 홀드아웃 경로 예측 | 일치 |
| Behavioral Parity | 89/100 |

| 로컬 PoC 평균 품질 | 88.9/100 |
| run-level 미입력 사실 생성 | 기준 8/8, PoC 0/8 |

E01과 E02만 전수 claim-level 라벨링을 수행했고, E03~E08은 중요 주장 중심으로
판정했다. 따라서 8개 실행의 claim-level 비율로 해석할 수 없다.

## 현재 저장소와의 차이

선행 PoC는 관찰된 분기를 재생하기 위해 동일 입력 자동 생성 같은 실험용 override를
포함했다. Funding Story AI는 제품 구현을 위해 해당 override를 제거하고 명시적 확인을
기본값으로 사용한다. 그러므로 89점은 설계 근거이지 현재 저장소의 서비스 동등성 점수가
아니다.
