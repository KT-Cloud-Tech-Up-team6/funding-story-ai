# 현재 한계

## 검증 범위

- 실제 검증된 category profile은 한국어 로봇청소기 한 종류다.
- 다른 제품군은 스키마 인터페이스만 수용하며 결과 품질을 검증하지 않았다.
- 템플릿 4개는 대규모 검색·부하·다양성 검증에 충분하지 않다.
- 웹 UI, 다중 사용자 API, 인증, 저장소와 배포 인프라는 포함하지 않는다.

## 모델과 비용

- 기준 텍스트 모델은 `gemini-3.7-flash`다.
- 접근 오류가 5회 연속 발생하면 `gemini-3.6-flash`로 폴백한다.
- 기본 비용표는 3.7의 확인 가능한 계약 단가가 없을 때 3.6 Standard를 대리값으로 쓴다.
- 이미지 단가와 토큰 환산은 공급자 정책 변경에 따라 달라질 수 있다.
- 실제 Billing과 크레딧 적용 여부는 원장에서 확인하지 않는다.

## 사실성과 규정

- 자동 검증은 외부 사실 확인을 수행하지 않는다.
- 메이커가 입력한 허위 정보를 참으로 판별할 수 없다.
- 광고법, 플랫폼 심사, 인증 표시와 지식재산권 판단은 사람 검토가 필요하다.
- 생성 이미지가 실제 양산 제품과 일치한다고 보증하지 않는다.

## 연구 해석

- 특정 서비스의 내부 구현, 템플릿 원본, 프롬프트와 검색 정책을 복원하지 않았다.
- 공개 성공 프로젝트에서 반복된 구조는 성과 원인이 아니라 템플릿 후보일 뿐이다.
- 선행 PoC의 Behavioral Parity는 로봇청소기 범위의 제한된 비교 결과다.

## 다음 검증 우선순위

1. 두 번째 제품군 profile과 홀드아웃
2. 외부 증빙 검색 또는 문서 검증 인터페이스
3. 다수 평가자 블라인드 품질 비교
4. 사람이 편집한 최종본까지 포함한 수정 비용 측정
5. API와 웹 편집기 경계 설계
