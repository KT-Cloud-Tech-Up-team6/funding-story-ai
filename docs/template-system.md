# 템플릿 시스템

템플릿은 긴 예시 문장이 아니라 스토리 생성 명세다. 제품 값은 브리프에서 가져오고,
템플릿에는 설득 순서와 필요한 정보 유형만 저장한다.

## 템플릿 구성

```text
기본 정보
├── 이름·카테고리·언어·타깃
├── 기본 분량·내레이션 모드
스타일
├── 톤·문장 스타일·컬러 팔레트
├── 타이포그래피·긴급성·CTA 방식
콘텐츠 전략
├── 핵심 메시지·제품 키워드
├── 성공 지표·강조 문구 그룹
레이아웃
└── 순서가 있는 section[]
```

각 section에는 역할, 기대 콘텐츠, 시각 힌트, 콘텐츠 타입, 이미지 필수 여부와 편집 가능한
HTML 자리표시자가 있다. `html_content`는 완성 문장이 아니라 결과 조립을 위한 골격이다.

## 포함 템플릿

| ID | 설득 축 | 섹션 |
|---|---|---:|
| `t01_performance_value_evidence` | 성능·가치·증빙 | 10 |
| `t02_problem_solution_automation` | 문제–해결·자동화 | 10 |
| `t03_lifestyle_social_proof` | 사용 상황·사회적 증거 | 10 |
| `t04_full_campaign` | 전체 캠페인 역할 | 12 |

템플릿의 일부 구조는 종료·목표 달성 공개 프로젝트에서 문장과 디자인을 제외하고 역할과
정보 유형만 추상화했다. 카탈로그의 출처는 구조 연구의 provenance이며 해당 구성이 성과를
유발했다는 의미가 아니다.

## 선택 방식

현재 선택기는 다음 요소를 사람이 설명할 수 있는 점수로 계산한다.

1. 브리프와 템플릿의 카테고리 일치
2. 콘텐츠 전략 키워드 일치
3. 사실·문제·자동화·타깃·증빙 신호
4. 제품군 profile에 선언된 soft boost

선택 결과에는 모든 후보 점수와 최종 선택 이유가 포함된다. 벡터 검색이나 숨겨진 모델
점수는 아직 사용하지 않는다.

## 확장 규칙

- 실제 제품 수치와 가격을 템플릿에 고정하지 않는다.
- 근거 없는 후기·인용·인증을 예시 문구로 넣지 않는다.
- 신규 템플릿은 JSON Schema, placeholder와 링크 검증을 통과해야 한다.
- template ID와 버전은 `templates/catalog.json`에 함께 등록한다.
- 제품군이 늘어나기 전에는 soft boost 계수를 일반화된 성능으로 표현하지 않는다.
