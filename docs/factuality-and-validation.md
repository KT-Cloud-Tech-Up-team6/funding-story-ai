# 사실성·검증

Funding Story AI는 외부 사실 확인 엔진이 아니다. 입력이 무엇을 근거로 제공했는지
추적하고, 결과가 그 범위를 넘어서는 알려진 패턴을 자동으로 차단하는 생성 가드다.

## 입력 상태

| 상태 | 의미 | 결과 표현 |
|---|---|---|
| `supported` | 연결된 증빙이 있는 주장 | 조건과 증빙 범위를 함께 표시 |
| `maker-stated-unverified` | 메이커가 제공했지만 외부 검증되지 않음 | 제공 기준임을 표시 |
| `unknown` | 값이 입력되지 않음 | 추정하지 않고 입력 필요 상태 유지 |
| `superseded` | 더 최신 값으로 대체됨 | 생성에서 제외 |

`source_fields`는 생성된 섹션이 사용한 브리프 ID 또는 경로를 기록한다. 이는 인용
정확성을 자동 보증하지 않지만 사람이 원문 필드로 되돌아갈 수 있게 한다.

## 자동 검사

- 템플릿과 결과의 섹션 개수·순서·역할
- 이미지 필수 섹션과 `image_intent`
- 브리프에 없는 숫자와 단위
- 폐기된 수치의 재등장
- 미제공 인증·가격·배송·AS·환불·일정
- 입력보다 강한 `자동`, `완전`, `방지`, `해결` 표현
- 미지원 앱·복귀·물통 관리 등 제품군 관행의 임의 보완
- 내부 ID가 제목과 본문에 노출되는 문제

검사 경고가 있으면 전체 JSON을 최대 한 번 다시 생성한다. 두 번째 결과에도 경고가
남으면 결과와 경고를 함께 반환한다.

## 이미지 안전 경계

- 참조 이미지가 있으면 본체·센서·도크의 형태와 색을 유지하도록 요청한다.
- 텍스트, 로고, 숫자, 인증 마크와 입력에 없는 구성품을 금지한다.
- 섹션별 생성 실패를 manifest에 남기고 다른 섹션을 계속 처리한다.
- 생성 직후 QA 상태는 `pending`이다.
- `pass` 또는 `conditional` 판정을 받은 이미지만 HTML 미리보기에 사용한다.

## 사람이 반드시 확인할 것

1. 메이커 제공 수치와 최신 제품 명세
2. 시험 조건과 외부 인증의 실제 문서
3. 광고 표현과 플랫폼 심사 정책
4. 리워드 가격·수량·배송 일정
5. 생성 이미지의 제품 동일성과 표시 적합성

따라서 모든 story result는 `review_required: true`다.
